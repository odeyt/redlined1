# North Star

Every repetitive task should eventually disappear.

Every important decision should become easier.

Every repair should improve the platform.

Every technician should become more productive.

Every advisor should sell with greater confidence.

Every owner should know exactly what to do next.

Every customer should receive a better experience.

Every day the platform should become smarter than it was yesterday.

---

## How to use this document

When a sprint, feature, or architectural decision is being debated, return to this page.

Ask: does this move us closer to any of these outcomes?

If yes — build it well.
If no — deprioritize it.
If it moves us away from any of these — do not build it.
