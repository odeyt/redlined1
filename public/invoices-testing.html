Fixes applied in this release:
  • Mark Paid now auto-creates a payment record → Reports revenue stays in sync
  • Status dropdown → Paid also sets paid_date and creates payment record
  • Invoice number collision fixed — uses MAX-based numbering, not row count
  • Print button now opens the full Preview modal (prints cleanly)
  • Prefill wired — Job Cards / Estimates / Repair Orders navigate to Invoices with customer pre-filled
  • Estimate → Invoice now navigates to Invoices module automatically after creating
  • Repair Order → Invoice now navigates to Invoices module automatically after creating
  • Job Card drawer has new "🧾 Invoice →" button

A1
Create new invoice — all fields
Create Happy path
  1. 1
    Navigate to Invoicing. Click + New.
  2. 2
    Verify Invoice # is auto-generated (e.g. INV-0005) and the field is read-only.
  3. 3
    Select a customer from the dropdown. Verify Customer Name field fills automatically.
  4. 4

    Add a second line: Description = "Oil Filter", Qty = 1, Rate = 12.50.
