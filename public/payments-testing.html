📋 Pre-conditions — set these up before starting any test

  1. You have at least 1 active customer in the Customers module (e.g. John Smith).
  2. You have at least 1 invoice in the Invoicing module with status Sent (e.g. INV-0002, total $129.99, customer = John Smith).
  3. Navigate to Settings → Portal Customization → Accepted Payment Methods. Confirm that at minimum these are enabled: Cash, Check, Credit Card, Zelle, Fleet Account. Save if you need to change anything.
  4. Open the Payments module. Note the current "Subtotal" at the bottom of the Payment Register (write it in the note line of A1).
  5. Open the Reports module. Note the current Total Revenue value before testing.

Section A — Record Payment (6 tests)
A1
Record a manual cash payment — standalone (no invoice)
Record Happy path
  1. 1
    Navigate to Payments. In the Record Payment panel, leave Link to Invoice as "— no invoice —".
  2. 2
    From the Customer dropdown select John Smith. Verify Customer Name field auto-fills.
  3. 3
    Set Amount = 50.00, Method = Cash, Currency = USD, Status = Recorded.
  4. 4
    Set Payment Date to today. Leave Reference # blank. Add Note = Walk-in cash payment.
  5. 5
    Click Save Payment. Verify toast "Payment recorded."
  6. 6
    Verify the new row appears in the Payment Register: Customer = John Smith, Method = Cash, Amount = $50.00, Status = Recorded.
  7. 7
    Verify the Register Subtotal increased by $50.00.
Expected result
Payment saved with correct fields. Appears in register. Subtotal updated.
