Features covered in this release:
  • Add / Edit part — all fields, validation, margin preview, quantity inline edit
  • Photo upload — Browse (multi-file) and Camera capture (device camera) in both the Add form and detail panel
  • Barcode scanner — USB/Bluetooth hardware scanner, on-screen scan input, lookup by barcode or part #
  • CSV Bulk Import — template download, file upload, row preview, progress bar, duplicate skip
  • Low Stock alerts — threshold trigger, out-of-stock badge, stock meter, reorder note copy
  • Stats bar — Total SKUs, Low Stock count, Cost Value, Retail Value, Margin
  • Search & filter — keyword search, category filter, combined filter
  • Reserve unit — decrement quantity, block when zero
  • Delete part — confirm dialog, Supabase persistence
